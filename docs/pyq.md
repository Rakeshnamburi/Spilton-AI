# Previous-year-paper library foundation

PYQ entries use GovernmentResources kind PYQ with exam, stage, optional subject, year, shift/date label, language, source URL/type and optional owned document. Metadata is manually entered; it is not evidence that an uploaded file really came from a historical examination.

Creation requires an explicit rights confirmation: official/publicly permitted material or the user's own permitted content. No paid coaching repository, pirated source, bulk downloader or redistribution catalog is integrated. Public original-source links are displayed with trust labels. “Download your uploaded copy” streams only the authenticated owner's existing file as an attachment; metadata-only entries do not have a fake download.

Actions: view metadata and excerpts, open original source, analyze with cited document RAG, or ask for practice using selected paper evidence. “Start as Mock” is disabled until a future phase. Generated practice is not presented as an original PYQ.

Analysis detects distinct numbered question first lines and matches explicit keywords to Percentage, Profit and Loss, Geometry, Reasoning and English labels. It returns review-required status, detected counts, matched topic counts and up to 20 actual question excerpts. Multi-line questions, formulas, scanned PDFs and unusual numbering can be missed. Categories may overlap; unmatched questions remain unclassified. A missing question boundary produces NO_RELIABLE_QUESTION_BOUNDARIES, not fabricated counts.

This is not official historical weightage, robust question extraction or difficulty estimation. A multi-year corpus and year-to-year occurrence analysis are not implemented. Tests use clearly labelled original development questions, not invented historical PYQs. The general RAG engine can analyze any legitimately uploaded Ready paper with real source citations.
