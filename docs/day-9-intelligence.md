# Day 9 intelligence layer

Capability routing remains deterministic and provider availability remains authoritative. Coding receives an expanded bounded context; exam context is included only for explicit preparation requests; selected documents route to RAG. `ConversationCompressor` provides a small extractive summary foundation for older user requests and never invents facts or stores hidden reasoning.

Chat logs capability, provider, model and routing latency through structured logging without request bodies, keys, or tokens. Provider failures remain sanitized. `IMultimodalProvider` defines a future image/file contract but is intentionally unavailable until a real configured vision provider exists.

Evaluation cases cover general, coding, RAG, exam, reasoning, research, agent, memory relevance, contamination and security routing. They remain safe deterministic cases; real web research is not claimed.
